This release covers the 41 pull requests merged between 2026-05-08 and 2026-10-29, and is a formal launch of a 2.0.0 state of moalmanac-db. It adds 60 indications: 9 from FDA, 22 from EMA, 14 from Health Canada (HC), and 15 from the Health Service Executive (HSE). Over the same period, the relational database in `referenced/` was rebuilt to align more closely with GA4GH VA-Spec, VRS, and Cat-VRS, and the database content is now licensed under CC BY 4.0.

## Feature updates

Repository and schema changes in this release:

- **Concept identifiers.** Integer primary and foreign keys were replaced with structured, self-describing strings, for example `stmt:fda:tevimbra:1:0` and `prop:vtxr:0` ([Issue 51](https://github.com/vanallenlab/moalmanac-db/issues/51)). Dereferenced per-concept files now use `_` instead of `:` in their file names, so they work on Windows.
- **Indications as Information Entities.** Indications now follow VA-Spec's Information Entity model: each one has its own contributions, `reportedIn` documents, and a `superseded_by` list. Dereferenced indications carry their statement description as an extension.
- **Status.** Every document, indication, and statement now has a `status`. Statement status is propagated from the indication: Approved or Accelerated gives Active, Superseded gives Superseded, and Withdrawn gives Deprecated. Statements now hold `status` and `indication` as extensions, per the VA-Spec Statement model.
- **Biomarkers.** Biomarkers were refactored to align with VRS and Cat-VRS. A new biomarker criteria table pairs each biomarker with a `present` flag. Biomarkers now dereference to Defining Allele, Copy Change, Function, Feature Context, Adjacency, and Defining Location constraints. New tables hold VRS alleles, sequence references, and sequence locations for curated genes' MANE Select transcripts, protein products, exons, chromosome arms, and whole chromosomes. Cat-VRS does not yet support sets of categorical variants, so `subjectVariant` is a placeholder and the biomarkers are carried as an extension.
- **JSON schemas.** Schemas were added for both the referenced and dereferenced records and are checked by the test suite. Extensions were removed from `referenced/` records, except biomarkers, to fit the API's SQLite databases. Gene fusions and translocations are now biomarker types of their own.
- **Codings.** The NCI Thesaurus is now the primary coding for diseases, with mappings to OncoTree (updated to the 2025-10-03 release). SNOMED mappings were removed. Scripts were added to download the NCI Thesaurus, OncoTree, and RefSeq.
- **Documents.** Each FDA label now has a dated document record alongside the evergreen one, and each FDA indication links to both its current label and the label that first approved it. `identification_number` was renamed to `regulatory_identifier`, and FDA values are now prefixed application numbers such as `NDA207103`. `company` is now nullable.
- **Licensing and documentation.** The database content is now licensed under CC BY 4.0. The scripts in `utils/` and `tests/` remain under GPL v2. A contributing guide, a Development section in the README, and a revised pull request template were added. The environment now uses Python 3.14.
