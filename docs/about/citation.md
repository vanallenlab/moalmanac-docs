# Citation

If you find MOAlmanac or any of its code useful, please cite:

> Reardon, B., Moore, N.D., Moore, N.S., *et al*. Integrating molecular profiles into clinical frameworks through the Molecular Oncology Almanac to prospectively guide precision oncology. *Nat Cancer* (2021). [https://doi.org/10.1038/s43018-021-00243-3](https://doi.org/10.1038/s43018-021-00243-3)

## Citing a database release

To cite a specific version of the database, use its Zenodo DOI:

- The concept DOI always points to the latest release: [10.5281/zenodo.17089309](https://doi.org/10.5281/zenodo.17089309).
- Each release also has a version-specific DOI, listed on the concept DOI's Zenodo page. DOIs have been minted since the 2025-09-04 release; for a DOI for an earlier version, please [contact us](https://dev.moalmanac.org/about#contact).
