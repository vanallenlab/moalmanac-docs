# Molecular Oncology Almanac

The Molecular Oncology Almanac (MOAlmanac) is a paired knowledge base and clinical interpretation algorithm for precision oncology. It associates molecular alterations with therapeutic sensitivity, therapeutic resistance and disease prognosis, both for individual events such as somatic variants, copy number alterations, fusions and germline variants, and for global features of a tumor such as tumor mutational burden, microsatellite instability, mutational signatures and whole-genome doubling.
